Off by default. Ordinary Inspector capture is independent. Only recognized creation editor and management routes are observed; private chats, browsing URLs, credentials and authored content are excluded from SCT recordings.

Disabled if empty. An explicitly authorized installed extension may report structured markers to this recording. It cannot read recordings, start/stop capture, trigger saves or control the account. The extension ID is validated by the browser.

Manual operation evidence

Optional local journal marker for the active recording. Verification here is an operator report, not an independent check of the saved creation.

Local recordings

Up to 24 recordings and 100,000 events across SCT. The recorder stops accepting new rows at its capacity; it does not silently overwrite older evidence. Expired recordings are cleaned on subsequent SCT activity. Export before retention expires.

What the evidence means

Page-bridge and QoL page events are untrusted observations. A button click is an attempt, a request is a submission and an HTTP success is only a response. A verification marker is a reported check. No operation is retried or performed by Inspector.

Reloads may leave gaps in buffered observations; committed rows survive extension and browser restarts. A selected-tab recording may need to be stopped and restarted if the browser restores it under another tab ID. Full diagnostics automatically expire within one hour.
